## Encoder placement dependency #1013

The installed candidate reports seven hardware ISO encoders and an eighth software
ISO encoder (`hardware-capacity-exhausted`), with one hardware session reserved
for Program. The default capacity probe stops at eight sessions. Thus it cannot
discover the ninth session required for the complete supported recording inventory.
NVIDIA's current [NVENC application note](https://docs.nvidia.com/video-technologies/video-codec-sdk/13.1/nvenc-application-note/index.html#nvenc-licensing-policy)
documents twelve sessions for non-qualified GPUs; this is context, not proof of
this driver's availability or sustainable throughput.

The correction bounds default discovery at nine (Program plus eight ISOs). It
uses actual probed availability, preserves lower-capacity software fallback and
retains the historical unprobed fallback. A regression fails against the old
eight-session default. Installed nine-session placement, sustained throughput,
source admission, recording/ISO pixels, registered camera identities and physical
display timing remain required. No queue/memory bound, output deadline, quality,
resolution or accepted frame-loss threshold is relaxed.
